# 公开与隐私说明

本仓库坚持最小必要公开：只发布理解、安装、运行和验证产品所必需的代码、文档和模拟示例。

原则上不公开：

- 真实客户、事项、案号、相对方、联系人和交易数据；
- 真实合同、律师函、案例工作簿、聊天记录和内部客户 Wiki；
- 本机路径、账号凭证、Cookie、token 和其他环境配置；
- 未经授权的律所信头、Logo、公章、签名、品牌模板和字体；
- Office/PDF 中的批注、修订、隐藏属性和无关作者信息；
- 中央开发库中的历史材料、缓存、日志和内部审查记录。

示例优先使用从零构造的模拟材料。确需使用脱敏材料时，不只替换姓名，还应检查事实组合、金额、日期、地点、文件元数据和上下文是否仍可能识别真实事项。
