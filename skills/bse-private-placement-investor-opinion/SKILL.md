# 北交所定增投资方法律意见书

## 核心边界

先识别委托关系和出具时点。本 Skill 服务于投资方内部决策法律意见，不替代：

- 发行人律师在申报阶段出具的发行法律意见书；
- 上市公司律师在发行完成后就发行过程、认购对象和法律文书出具的专项法律意见书；
- 主承销商关于发行过程和发行对象合规性的专项核查意见。

若事实不符合“北交所上市公司普通股向特定对象发行、投资方拟参与竞价认购”，停止套用模板，重新确定规则和结构。

## 必读资源

1. 开始起草或实质复核前，完整读取 `references/writing-guide.md` 和 `references/drafting-decisions.md`。
2. 引用法条或判断程序时，读取 `references/rules-verbatim.md`，并在出具日重新通过法宝、元典或发布机关官网核验版本。
3. 形成结论前，读取 `references/review-checklist.md`。
4. 需要快速了解模板内容时读取 `references/anonymized-opinion-text.md`；生成 Word 时复制 `assets/templates/大成成都_北交所定增投资方法律意见书_脱敏模板.docx`，不得修改资产原件。

## 工作流

### 一、锁定出具目的、时点和交易类型

至少确认：

- 委托人为投资方还是发行人；
- 发行方式是否为竞价，发行对象是否尚未确定；
- 当前材料所处的实际阶段，以及投资人要求法律意见采用的拟制出具时点；
- 北交所审核、中国证监会注册是否已经完成，尚缺哪些审核注册文件及最终发行参数；
- 法律意见书用于上会、报价授权、签约还是投后留档；
- 投资方是否为国有股东或国有实际控制主体；
- 拟认购金额是否已确定，是否可能触发不同内部或国资权限；
- 是否已取得认购邀请书、申购报价表、缴款通知和认购合同。

必须区分“起草时的实际材料阶段”和“投资人要求的拟制出具时点”。若投资人明确仅在北交所审核通过及中国证监会注册完成后上会，即使起草时尚未完成审核注册，正文和结论也应按审核注册完成后的出具口径搭建，不得直接写成仍待审核注册。

前述处理不是把尚未发生的事实认定为已有材料证明。对尚未取得的北交所审核文件、中国证监会注册批复，以及需根据该等文件或注册稿更新的发行数量、募集资金、价格、期限等内容，应留出明确占位并添加 Word 批注，说明“待取得何种文件后、依据何处记载、核对更新哪些字段”。该版本仅为待更新拟制稿；在文件取得、逐项复核、填入事实并清除相应批注前不得签发。

### 二、建立材料和主张台账

优先取得并核对：

- 投资方案、金额上限、报价上限和资金来源；
- 发行人募集说明书最新稿、董事会和股东会文件；
- 发行人律师最新法律意见书及补充意见；
- 保荐书、审核问询及回复；
- 北交所审核意见和中国证监会注册批复；
- 投资方营业执照、章程、股权结构、内部投资制度和权责清单；
- 国家出资企业投资制度、负面清单、上会清单；
- 管理信息系统备案材料、国有属性证明、证券账户材料；
- 认购邀请书、报价表、认购合同、缴款通知（如已形成）。

分别建立“现有材料事实”和“拟制出具时点事实”台账。拟制稿可以按投资人要求采用审核注册完成后的口径，但每个最终签发结论仍须对应届时取得的实际材料；材料缺口必须通过占位和批注显性保留。发行人专业机构公开意见可作为支持材料，但不得把注册批复表述为监管机关对全部事实和投资价值的实质保证。

### 三、逐环节深挖直接规则

对正文每一项意见分别建立“事项—主管或办理主体—上位依据—直接操作规则—项目文件—结论”链条。不得满足于找到一份概括性、衔接性规则；应继续检索该环节实际主管、审核、交易、登记或账户办理机构发布的更具体规则、指南和材料要求，直到足以直接支持所发表的程序和主体结论。

新增股份登记同时核对北交所衔接规则和中国结算直接登记规则，只是这一方法的典型应用。投资者适当性、竞价发行、国资审核与系统备案、SS/CS 标识、认购缴款、限售及上市等环节也应按同一方法检索，不得把“双层规则”要求局限在股份登记一节。

复制 `assets/legal-source-ledger.template.json` 建立事项法律依据核验台账。法规效力和条文原文优先通过可直接调用的法宝核验；法宝不可用时立即使用元典；二者均未安装或不可用时，可以使用法规、规则发布机关官网，但必须定位发布机关的正式文本，并同步检索修订、废止或失效文件，不能仅凭搜索摘要或转载页认定现行有效。仍无法完成权威核验的，标记待核验，签发稿不得通过最终审计。签发时应在法律意见书出具日重新核验并更新台账日期。

法律意见书以还原规则原文为原则。正文使用“规定：‘……’”或其他明确引号标示原文时，除排版空白外应与核验台账中的条文连续文本一致；确有必要归纳时，不使用原文引号，并尽量保留适用主体、条件、例外、程序和法律效果。代码比对原文引文，归纳是否忠实和幅度是否必要仍作法律语义复核。

### 四、按固定问题树起草

原则上依次处理：

1. 本次投资的交易方案；
2. 发行人与投资方主体资格；
3. 投资方内部决策、国家出资企业审核和管理信息系统备案；
4. 获配后的发行结果报送和新增股份登记；
5. 股份锁定期；
6. 国有股东或国有实际控制股东标识（适用时）；
7. 认购邀请、申购报价、认购合同和缴款程序；
8. 结论意见。

只有确有必要时调整结构。不要把发行期限、分期发行和竞价方式混入“发行人主体资格”。不要用工商信息表代替投资者准入分析。

### 五、分别控制关键结论

#### 发行人

按投资人要求的拟制出具时点作有限确认：依法设立、有效存续、仍为北交所上市公司，本次发行已经履行审核和注册程序。起草时尚未取得审核注册文件的，保留文件名称、日期、文号及受其影响的发行参数占位并添加待更新批注；最终签发前必须取得并核验。审核意见和注册批复证明程序状态，不等同于监管机关保证全部申请文件真实或投资具有价值。

#### 投资方

先判断其是否属于发行方案允许的投资者类型，再判断实际参与条件。机构投资者不适用个人投资者“50万元资产、24个月交易经验”的量化门槛，但“境内法人”并不当然等于可获配。至少核对认购邀请书条件、禁止参与竞价的关联关系、账户和北京市场标识、资金来源、内部和国资批准。

无认购邀请书时，只发表“基本主体资格”或“主体类型符合”的有限意见；不要无条件确认最终认购资格。

#### 国资程序

区分三件事：

- 由国家出资企业或国资监管机构审核批准；
- 国家出资企业批准事项通过管理信息系统备案并取得统一编号备案表；
- 实际持股变化后通过系统报送股份变动情况。

第二项和第三项不是同一义务；SS/CS 账户标识也不是交易备案本身。

#### SS/CS 标识

按一码通账户的国有属性处理，不按单只股票处理。先认定 SS、CS 或不适用，再根据中国结算现行账户指南判断开户时申报或既有账户变更。不得当然认定统一编号备案表就是中国结算要求的国有属性证明文件；需要向主管国资部门或开户代理机构确认。

#### 认购文件

竞价发行中，发行对象确定后才签署认购合同，出具意见时尚未形成合同通常是正常程序状态。不要写“待取得合同后再提交本所审查”，除非委托范围确实包含后续专项服务。法律意见应提示投资方按规则核实认购邀请书、报价授权、保证金、配售、中止发行、合同、缴款和登记程序。

### 六、形成大成 Word

先生成事项工作副本，禁止直接修改模板资产：

~~~bash
python scripts/instantiate_template.py \
  --output /absolute/path/事项名称_DC_YYYYMMDD.docx
~~~

在工作副本中替换占位符，保留大成成都既有封面、页眉页脚、目录、正文和签署页样式。使用当前 Agent 的 Documents 能力生成或修改 DOCX，并执行：

~~~bash
python scripts/audit_opinion.py /absolute/path/法律意见书.docx \
  --sources /absolute/path/法律依据核验.json
python scripts/audit_opinion.py /absolute/path/法律意见书.docx --final \
  --sources /absolute/path/法律依据核验.json
~~~

`--final` 必须在审核注册文件取得并完成更新后、律师定稿前运行。拟制工作稿可以故意保留审核注册文件和待更新发行参数的占位符、批注；签发稿存在占位符、修订、批注、旧规则名称、未经权威来源核验的法规、与核验文本不一致的原文引文、空结论序号或关键章节缺失时不得交付。

文件名使用 `_DC_YYYYMMDD` 后缀，不使用“修订稿”字样；作者和最后修改者使用“大成律师”，时间使用中国标准时间。

### 七、渲染和交付

1. 使用 Documents skill 的 `render_docx.py` 渲染全部页面；
2. 逐页检查封面、目录、表格、分页、页眉页脚、签署页和修订显示；
3. 若无头 LibreOffice 将中文替换为方框，改用本机 Microsoft Word 导出 PDF或使用 macOS Quick Look 复核；这是渲染器字体替代问题，不得据此改写正文；
4. 形成内部“正文意见—事实及法律前提—对应结论”勾稽表，逐项判断结论是否遗漏前提、扩大意见或改变主体和程序阶段；脚本只复核主题覆盖、时点冲突和编号等可机械判断事项；
5. 删除空序号和重复结论；
6. 重新运行 `audit_opinion.py --final --sources ...`；
7. 默认只交付最终 DOCX；用户要求时再生成 PDF。

## 不得出现的常见错误

- 把起草时尚处审核阶段直接写入按“审核注册完成后”拟制的正文或结论；或者反过来，不留占位、不作批注便把尚未取得的审核注册文件写成已有材料证明的事实；
- 对某一环节只引用概括性或衔接性规则，未继续查找实际办理机构发布的直接、细化规则；股份登记仅引用北交所业务指南只是这一错误的典型表现；
- 把投资者个人50万元和24个月门槛套给机构投资者；
- 把管理信息系统备案、变动报送和SS标识写成同一事项；
- 把投资方写成新增股份登记的申请人；
- 尚无认购合同却对其条款完备性和效力作肯定意见；
- 在一次性法律意见书中承诺后续由本所继续审查认购文件；
- 结论复制旧模板，和正文阶段、审批路径或程序不一致。
