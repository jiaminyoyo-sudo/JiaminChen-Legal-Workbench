# 起草与交付核查清单

## 一、项目定位

- [ ] 委托人为投资方。
- [ ] 标的为北交所上市公司普通股向特定对象发行。
- [ ] 已识别竞价、提前确定对象、简易程序或分期发行路径。
- [ ] 已分别记录起草时的实际审核注册阶段和投资人要求的拟制出具时点。
- [ ] 投资人仅在审核注册完成后上会的，正文和结论已按该拟制时点撰写。
- [ ] 已区分本意见与发行人申报法律意见、发行完成后专项意见。

## 二、事实与材料

- [ ] 发行人主体和上市状态有当前材料支持。
- [ ] 发行方案使用募集说明书最新版本。
- [ ] 拟制稿尚未取得北交所审核文件和证监会注册批复的，名称、日期、文号及待更新发行参数已留空并添加具体待更新批注。
- [ ] 签发稿中的北交所审核文件和证监会注册批复名称、日期、文号已填写并与原件核对。
- [ ] 投资方章程、股权结构和实际控制链已核对。
- [ ] 内部制度和权责清单是现行版本，金额档位与拟申购上限一致。
- [ ] 国家出资企业审核机构和权限已核对。
- [ ] 关联关系、资金来源、证券账户和北京市场标识已有说明或限定表述。
- [ ] 无全文的内部制度只按客户确认内容引用，并在底稿说明证据边界。

## 三、法律结论

- [ ] 发行人主体资格未混入发行期限和竞价规则。
- [ ] 注册批复未被表述为监管机关对投资价值或全部事实的保证。
- [ ] 机构投资者未套用个人50万元、24个月门槛。
- [ ] 投资方仅在证据允许范围内被确认具有基本或最终认购资格。
- [ ] 已核查《再融资办法》第四十五条禁止参与竞价情形。
- [ ] 内部决策、国家出资企业审核、系统备案和变动报送已经分开。
- [ ] SS/CS 认定与系统备案已经分开。
- [ ] 每项意见均已检索上位依据、主管或审核机构规则及实际办理机构的直接细化规则。
- [ ] 实际引用法规均已进入事项法律依据核验台账，并记录现行效力、权威来源、核验日期和所引条文原文。
- [ ] 明示为法规原文的引文已逐字核对；归纳表述未遗漏主体、条件、例外、程序和法律效果。
- [ ] 新增股份登记已由北交所衔接规则继续核对中国结算直接登记规则；其他环节也已按同一方法深挖。
- [ ] 认购合同尚未形成时未对具体条款和效力作肯定意见。
- [ ] 限售期按发行对象类型判断为6个月、12个月或其他法定期间。

## 四、结论勾稽

- [ ] 主体资格结论与正文一致。
- [ ] 正文与结论均采用投资人要求的拟制出具时点，材料缺口通过占位和批注明示。
- [ ] 审批机构和金额档位与正文一致。
- [ ] 报价、签约、缴款、登记顺序与正文一致。
- [ ] SS/CS 和限售结论与正文一致。
- [ ] 无空结论序号、重复结论或旧模板残留。
- [ ] 已形成“正文意见—事实及法律前提—对应结论”勾稽表，并人工复核语义一致性。

## 五、Word与签发

- [ ] 使用大成成都模板并保留封面、页眉页脚、目录和签署页。
- [ ] 文件名以 `_DC_YYYYMMDD` 结尾，不含“修订稿”字样。
- [ ] 作者和最后修改者为“大成律师”，时间为中国标准时间。
- [ ] final 文件对应的审核注册文件已经实际取得并核验，且无占位符、修订、批注和客户敏感元数据。
- [ ] 已运行 `scripts/audit_opinion.py --final --sources 法律依据核验.json`。
- [ ] 已渲染全部页面并逐页检查表格、分页和签署页。
