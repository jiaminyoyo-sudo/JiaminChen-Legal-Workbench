# 实务文章与公众号来源优先级

本文件用于“先找高质量实务文章/问答，再倒查案例”的路径。它不是来源白名单；每次检索仍应结合具体问题、发布日期、发布主体、是否有原始案例链接和是否能倒查全文来判断。

## 使用原则

1. 法答网优先。中国法律语境下，法答网属于最高人民法院主导的法律政策/裁判规则问答入口；如问题适合从法答网寻找裁判口径，应先检索法答网。
2. 司法机关公开来源优先于商业机构文章。法院官网、法院公众号、人民法院报、中国法院网、最高人民法院/高院/中院公开文章，通常优先于律所文章。
3. 律所文章适合作为“发现线索”和“观点地图”，不能替代案例原文、法条原文或法院来源。
4. 微信公众号生态优先使用 web-access 进入；如果需要保存公众号全文，再配合 wechat-article-archive-codex。
5. 表格或源素材记录必须保留文章标题、发布主体、发布日期、URL、核心观点摘要、引用法规/规则摘要、采用/排除理由。

## 默认分层

| 层级 | 来源类型 | 例子 | 用法 |
| --- | --- | --- | --- |
| A1 | 法答网、最高人民法院直接发布渠道 | 法答网、最高人民法院官网、最高人民法院公众号 | 优先检索；可作为裁判口径线索，但正式引用仍需核对法条/案例原文。 |
| A2 | 司法机关权威媒体和官方平台 | 人民法院报、中国法院网、中国审判、最高人民法院司法案例研究院相关发布 | 优先检索；适合发现典型案例、裁判规则和法院观点。 |
| A3 | 地方法院官方发布 | 各地高院/中院/专门法院官网和公众号 | 按地域和审级筛选；同省高院、中院来源对地方问题更有参考价值。 |
| B1 | 高质量争议解决/诉讼团队文章 | 天同诉讼圈、金杜研究院、中伦视界、君合法律评论、方达律师事务所、通商律师事务所、环球律师事务所、大成研究等 | 用作检索线索、观点地图和案例倒查入口；不得直接替代案例原文。 |
| B2 | 学术/专业媒体和数据库文章 | 法律适用、人民司法、北大法宝/威科/法信公开文章等 | 用作理论或规则背景；需要核对原始出处。 |
| C | 普通转载、营销号、无署名文章 | 未标明作者/来源、转载链不清、只给结论无案号的文章 | 原则上不优先；仅作为关键词线索，采用时说明局限。 |

## 检索建议

- 组合检索词：争议焦点 + 法答网、争议焦点 + 最高人民法院、争议焦点 + 人民法院报、争议焦点 + 法院 公众号、争议焦点 + 案号。
- 公众号检索：优先通过 web-access 使用真实浏览器路径；必要时先从搜索引擎定位文章，再用浏览器打开微信原文。
- 记录未采用材料：若文章权威但与问题不匹配，或只有观点没有案号，也要在源素材记录中简要说明，避免重复检索。

## 交付留痕字段

源素材记录至少包括：

| 字段 | 说明 |
| --- | --- |
| 标题 | 文章、问答或公开材料标题 |
| 发布主体 | 法答网、法院、媒体、律所、作者团队等 |
| 发布日期 | 无法确认时写“待确认” |
| URL | 原始链接，微信公众号尽量保留 mp.weixin.qq.com 原文链接 |
| 来源层级 | A1/A2/A3/B1/B2/C/待评估 |
| 采用状态 | 已采用/未采用/仅作关键词线索 |
| 关联案例 | 案号或案例名称；没有则写“未列明” |
| 核心观点摘要 | 文章具体提出的裁判观点、实务判断或风险提示，避免只写“规则背景” |
| 引用法规/规则摘要 | 文章引用的法规、司法解释、会议纪要、裁判规则或监管规则；没有则写“未直接引用” |
| 备注 | 采用理由、排除理由、待倒查事项 |
