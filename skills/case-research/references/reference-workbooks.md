# 参考案例表

本技能参考以下既有案例表的结构和写法：

`reference-workbooks/投资人实现公司方承担责任诉讼结构案例表_含规则梳理_DC_修订稿20260609.xlsx`

本公开副本只保留 Skill 内参考工作簿，不记录原始事项绝对路径。

## 可复用做法

1. 以“案例明细”和“规则梳理”分表组织。
2. 案例明细中保留请求结构、核心主张、法院原文、裁判结果。
3. 规则梳理中保留规则原文和与本案有关的句段。
4. 通过链接保留可核验来源。

## 本技能调整

本技能默认案例表不设置“参考权重”“对本问题的参考意义”“律师适用说明”等字段；适用边界和律师分析放在正文。

参考 workbook 中的“诉讼结构”“请求权外观”“案例引用规则/裁判规则依据”等列适合复杂专题研究。若用户只需要咨询回复中的案例表，使用 `output-table-template.md` 的默认字段，并额外保留“线索文章/源素材链接”。
