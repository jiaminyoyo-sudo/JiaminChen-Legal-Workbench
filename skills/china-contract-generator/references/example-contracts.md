# 脱密合同示例使用说明

两份 Word 均来自律师与客户多轮协作后的定稿/优选稿，已移除客户名称、项目名称、产品名称、注册证编号、地址、核心金额数量及文档个人元数据。仅在项目内没有更优先的客户定稿合同时使用。

## 选择规则

### 医疗产品采购及病例资料合作协议

文件：[医疗产品采购及病例资料合作协议_脱密示例.docx](医疗产品采购及病例资料合作协议_脱密示例.docx)

适用于采购、服务、病例资料、患者授权、品牌传播等多种关系交织的非常规合作。重点学习：

- 用鉴于条款和“项目性质”正面界定真实交易，而非依赖否定式排除；
- 将资质、诊疗、授权、去标识化、资料真实性和产品流向等可控责任配置给医疗机构；
- 将资料交付、补正、书面验收与现金/产品两种对价方案衔接；
- 区分合同正文中的相对方责任与批注中的客户内部使用边界；
- 对患者授权、信息使用、不良事件、反商业贿赂、解除后资料与产品处理形成闭环；
- 通过一般违约、重大违约、迟延责任和损失范围实现分层追责。

这是强监管复合交易的结构示例，不是医疗项目的通用合法性结论。引用其中医疗、个人信息、广告、研究或反贿赂规则前必须重新核验现行依据和实际业务。

### 物料采购合同

文件：[物料采购合同_脱密示例.docx](物料采购合同_脱密示例.docx)

适用于采购方立场的原材料、包装材料或一般物料采购。重点学习：

- 主体资质、产品来源、权属与可追溯保证；
- 质量标准按合同、附件、样品、质量协议和强制标准衔接；
- 签收、初步验收、专业检测与隐蔽瑕疵分层处理；
- 付款节点、质保金、发票与验收条件联动；
- 退换货、替代采购、价差、召回和监管调查的责任闭环；
- 一般违约、质量违约、重大质量后果及损失范围的分层表达。

示例保留了医疗器械生产企业采购语境。用于其他行业时，应删除不适用的医疗器械、复验期、召回或监管表述，并按实际产品重建质量标准。

## 使用边界

1. 优先级始终为：项目 `AGENTS.md`/wiki、客户需求、客户定稿合同高于本示例。
2. 只加载与当前交易最接近的一份；复合交易确有需要时再交叉参考。
3. 不照抄占位符、金额、比例、期限、违约金或法条；逐项确认商业依据和可执行性。
4. 先完成法律关系底稿，再借鉴结构；不得先套示例后反推法律关系。
5. 示例中的批注用于学习“依据—理由—建议”的推理方式，不应原样复制到其他项目。
