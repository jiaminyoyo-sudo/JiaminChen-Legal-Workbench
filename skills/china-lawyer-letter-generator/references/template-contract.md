# 大成成都信头纸模板使用约定

## 基准

- 资产：`assets/大成成都信头纸模板.docx`
- 用户提供的来源文件 SHA-256：`1767ffc95c7d430c27706bd0423c0d8a30e0560a27a33972e0265190587853e6`
- 技能内资产在不改变文字、图片和布局的前提下，将宋体、黑体、仿宋、华文中宋的中文字体别名规范为 `SimSun`、`SimHei`、`FangSong`、`STZhongsong`，提高 Word/LibreOffice 兼容性
- 中央规范化资产 SHA-256：`7948fea90e09fb069a6f76df33d914c5a8ee633237cf550cf973c78c7a3f20ea`
- 公开脱敏资产 SHA-256：`bc57bc4c8d94bc00d79b6dedfedf6f94927d345367795ae734e91e866e192ce7`；公开副本仅清除个人、WPS 和本机路径元数据，不改变信头文字、图片或布局
- 页面：A4 纵向，单节，首页不同；模板示例共两页
- 信头源文件页边距：左 2.54cm，右 2.54cm，上 1.27cm，下 2.54cm
- 律师函生成稿页边距：左 3.18cm，右 3.18cm，上 2.54cm，下 2.54cm；生成器只在复制出的 `w:sectPr` 中调整 `w:pgMar`，保留页眉页脚引用、首页不同和页码字段
- 页眉：首、续页分别设置；包含大成标识，首页另含成都办公室地址信息
- 页脚：首、续页分别设置；包含说明文字及“当前页/总页数”字段
- 律师函固定排版：标题华文中宋 18pt 加粗；案号宋体 12pt；摘要及一级标题黑体 12pt；正文宋体 12pt、1.5 倍行距、首行缩进两字符

## 使用规则

1. 将模板视为信头和版式资产，不把正文中的格式说明视为律师函内容。
2. 始终复制后写入，不修改模板原件。
3. 保留页眉、页脚、图片、页码字段、节属性、主题、字体表和自定义部件。
4. 生成器只替换 `word/document.xml` 的正文内容、调整复制节属性中的页边距并更新作者元数据；规范化后的其他包部件保持原内容。
5. 不因示例模板有两页就强制律师函两页；页码字段应按最终分页更新。
6. 不把该资产描述为“律师函模板”。它是大成成都信头纸；律师函正文按固定 11 部分结构生成，具体内容由模型根据事项判断。
7. 日后替换信头源文件时，先运行 `scripts/normalize_template_fonts.py 原文件 新资产`，再重新记录源文件与规范化资产的 SHA-256，并完成首、续页渲染检查。

## 已知渲染差异

在缺少 `FangSong`、`STZhongsong` 或适当中文替代字体的 LibreOffice 环境中，中文仍可能显示为方框或局部缺失，首页中文地址也可能异常拆行。生成和验收时：

- 优先在安装相应字体的 Word 环境检查；如标准渲染器因隔离临时 `HOME` 无法读取本机中文字体，使用 `scripts/render_letter.py` 二次渲染；
- 仍须用渲染图检查图片、页眉、页脚、页码、分页和正文位置；
- 字体替代导致的缺字不得被误判为源模板内容缺失；
- 对外发送前必须由律师在实际签发环境再次检查。

生成后运行 `scripts/audit_letter_docx.py`，核对 11 部分标记、两处经办律师手签栏、中文日期、盖章及骑缝章提示、附件、页边距、作者元数据和包部件保留情况。
