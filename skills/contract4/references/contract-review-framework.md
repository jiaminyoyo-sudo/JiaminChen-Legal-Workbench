## 1. 事实与判断分层

合同审查时将信息分为四类：

- **已确认事实**：来自用户、背景材料、合同和可靠项目记忆；
- **作业假设**：材料不足但不影响整体推进，必须显式说明；
- **法律判断**：说明适用规则、边界和不确定性；
- **商务偏好**：价格、期限、排他、责任额度等由客户决定，不伪装成法律结论。

当事实冲突时，以用户最新明确说明和原始材料为准；不能判断时保留“待确认”。

## 2. 法律关系地图

不要只列签约双方。至少回答：

| 问题 | 审查重点 |
|---|---|
| 谁出钱、谁收钱 | 付款义务、税费、发票、退款和对账 |
| 谁实际履行 | 签约主体、关联方、员工、分包商、平台和合作机构 |
| 谁控制成果 | 验收、变更、使用、交付和风险转移 |
| 权利从哪里来 | 所有权、著作权、商标、肖像、数据、许可和转授权链条 |
| 谁承担法定义务 | 行政许可、医疗、广告、劳动、个人信息等不可简单转移的义务 |
| 谁决定处理目的和方式 | 委托处理、共同处理或独立第三方提供 |
| 当前合同能解决什么 | 当前当事人能够承诺、处分和承担的事项 |
| 还需要什么 | 其他协议、内部审批、告知同意、证照核验或履行留痕 |

合同名称不是法律关系结论。“服务”“合作”“顾问”“授权”都可能同时叠加买卖、委托、许可、居间、数据处理或监管关系。

## 3. 交易闭环

### 正常履行闭环

```text
需求/订单 → 履行准备 → 交付 → 验收/异议 → 整改 → 结算/付款 → 权利移转 → 资料留存
```

逐步核对主体、触发条件、期限、标准、证据和未完成后果。

### 异常处理闭环

```text
异常发现 → 通知 → 停止扩大 → 调查取证 → 整改/替换/退款 → 损失承担 → 解除/终止 → 存量和交接
```

避免只写“违约方赔偿损失”，但没有通知、整改、终止和证据机制。

## 4. 风险分级

### 必须修改

- 主体错误、授权不足或签署权限缺失；
- 条款违法、明显无效或无法实现交易目的；
- 客户承担无上限、不可控或与业务不匹配的责任；
- 标的、交付、验收、付款等核心机制缺失；
- 权利链、数据流或监管责任出现实质断裂。

### 建议修改

- 履行标准、期限、证据或救济不清；
- 条款冲突、概念混用或责任触发不明确；
- 客户市场地位未得到合理反映；
- 可能造成高频争议但不当然影响效力。

### 批注提示

- 有利条款无法排除强制性规则；
- 当前合同不能替代其他主体法定义务；
- 实际履行前需取得具体授权、审批或证照；
- 商业事实不清但不宜擅自收窄客户权利。

### 商务确认

- 价格、期限、最低采购量、排他范围；
- 违约金或责任上限的具体金额；
- 是否接受对方市场惯例或交易条件。

### 运营落实

- 订单、验收、对账和送达留痕；
- 资质、授权、广告样件和个人信息同意核验；
- 数据权限、删除、事故通知和证据保存；
- 需要另签的附件、授权书、委托处理或合作协议。

## 5. 法律核验

以下判断不得仅依据通用经验：

- 高监管行业准入、广告、数据、劳动、消费者、医疗和金融规则；
- 格式条款提示说明、免责、责任限制及无效风险；
- 法定解除、任意解除、违约金调整、管辖和仲裁效力；
- 权利主体、许可范围、个人信息单独同意等多层权利问题；
- 新法、新规、监管指南或裁判口径可能变化的事项。

核验后在批注中只写与客户决策有关的依据和结论，不堆砌法条。项目已有稳定wiki口径时先比对事实是否一致。

## 6. 客户利益与条款效力

客户利益不是简单增加己方权利、删除己方义务。至少同时评估：

1. **合法有效**：是否违反强制性规则、格式条款或公序良俗；
2. **可执行**：责任主体、触发条件、金额和证据是否明确；
3. **可成交**：对方是否可能接受，是否影响核心合作；
4. **可运营**：客户内部是否具备审批、通知、核验和留痕能力；
5. **可举证**：争议时能否证明订单、履行、违约和损失；
6. **客户收益**：保护是否与交易金额、频率和风险相称。

强势方可争取更多控制，但不自动适用“我方任意解除、单方调价、全面免责”。弱势方也不应堆砌无法被接受或执行的保护条款。

## 7. 条款定性示例

### 期限

- 客户付款期：通常是客户义务期限，适当延长可能有利；
- 客户审核或异议期：通常也是权利保护期，不应机械缩短；
- 对方交付期：通常是对方义务期限，应与项目进度匹配。

### 责任上限

- 双向统一上限可能同时限制客户获得赔偿；
- 己方责任上限是否合理，应结合合同金额、保险、可预见损失和强制性责任；
- 对方责任也不宜无条件无限，应区分故意、重大过失、侵权、保密、数据和一般违约。

### 违约金

固定金额、比例或日违约金没有天然优劣。应结合合同金额、违约类型、损失可能性、履行阶段和司法调整风险确定；金额无法确认时留作商务选择，不擅自填入示例数字。

### 单方权利

单方解除、调价、解释权和免责条款应核对触发条件、通知、存量处理及格式条款风险。市场强势只能提高谈判空间，不能替代效力审查。

## 8. 修订自检

每项核心修改完成后检查：

```text
原条款解决什么问题？
它约束谁、保护谁？
本次修改属于必须修改、建议修改还是批注提示？
修改后是否更符合客户交易目标？
是否仍然合法、可执行、可成交？
是否引入新的冲突、空缺或无法履行义务？
客户未来需要做什么操作或留痕？
```

如果最后两个问题不能回答，优先补充条件、批注或操作提示，而不是继续扩张正文。
